# Welcome Screen Integration Architecture

## Overview
The Welcome Screen integration provides an entry point for users to generate project configurations (manifests) via natural language prompts using AI. This feature integrates directly with the existing project lifecycle and wizard orchestration.

## Component Interactions
1. **`WelcomeManifestDialog`**: A modal dialog wrapper for the `WelcomeScreen` component. It captures user intent when they choose to start a project from an AI prompt.
2. **`WelcomeScreen`**: Handles the UI for entering the natural language description, triggering the AI call, and showing loading/error states.
3. **`WizardStepRouter`**: Modified to handle `autoGeneratedSteps` indicating which parts of the wizard are pre-filled by the generated manifest.
4. **`useProjectLifecycle`**: Coordinates the side effects when a manifest is successfully generated. Uses `handleWelcomeManifestGenerated` to determine if the manifest can be applied immediately or if the user must be prompted to discard/save an ongoing draft.

## Data Flow
1. User submits a natural language description.
2. An API request is made to the AI service, returning a YAML string representing the hexagonal architecture manifest.
3. The YAML string is passed to `parseManifestToWizardData` from `@hexagen/wizard-orchestration`.
4. The parser validates the YAML against the schema and converts it into a `WizardData` object.
5. `analyzeManifestCompleteness` evaluates which wizard steps are fulfilled by the generated data.
6. The `useProjectLifecycle` hook resets the form with this data, updates the UI to reflect the populated steps, and routes the user to the first incomplete step or the summary step.

## Error Handling
Error handling is centralized in `errorMessages.ts` to provide user-friendly feedback based on API and parsing failures.
- **Categories**: `NETWORK`, `TIMEOUT`, `RATE_LIMIT`, `PARSING`, `UNKNOWN`.
- The `classifyError` function inspects the thrown error message or HTTP status to assign a category and return the appropriate localized string.

## Edge Cases
- **Active Draft Exists**: If a user tries to generate a new manifest while an existing project draft is active, `useProjectLifecycle` intercepts the action and opens a `new-project` dialog, prompting the user to either `handleSaveAndNew` or `handleDiscardAndNew`.
- **Incomplete AI Manifests**: If the AI omits certain required fields, `analyzeManifestCompleteness` ensures the user is dropped at the correct wizard step to manually complete the missing information.
