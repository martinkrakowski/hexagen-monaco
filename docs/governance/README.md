# Governance

This section contains human-readable documentation focused on **architectural governance and boundary enforcement**.

It is distinct from general feature work or implementation planning.

## Documents

- [Architectural Governance Debt](debt.md) — Living register of active and recently resolved governance debt.
- [Resolved Archive](resolved/arch-linter-2026-05.md) — Historical record of the major Arch-Linter v2 governance improvements.

## Scope

This section primarily covers:
- Architectural boundaries and layer rules
- Subpath conventions and server/client separation
- Linter enforcement mechanisms
- Manifest and governance tooling hygiene

## Relationship to Other Sections

- **Planning** — Governance constraints heavily influence implementation sequencing.
- **Decisions** — Many governance rules originate from or are refined by ADRs.
- **Architecture** — High-level boundary models are enforced here.
