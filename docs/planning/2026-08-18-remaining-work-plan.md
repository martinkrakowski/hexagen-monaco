**Concurrency.** Prefer at most **4** open PRs labeled `wave-a0` / `wave-a1` / `wave-b` / `wave-c` / `wave-d` combined. Hotfixes carry **no** `wave-*` label and do not count. This is an operating rule, not a modelled CodeRabbit quota (the earlier “74 / 7 days, refill 1/hour” figures do not reconcile and are withdrawn). A GitHub Action that fails the 5th labeled PR is optional infrastructure (F-4); it is not a Wave 0 blocker. Do not spawn a comment-sweeper while a builder is still running.
