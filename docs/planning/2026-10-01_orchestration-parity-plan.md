## 4. What this plan does not do

- It does not build an opencode `tool.execute.before` block-list plugin (D14). That plugin would run with the server's full privileges, and it waits on the owner's security review.
- It does not publish. Every release is the owner's action. Releasing from CI with provenance needs an `orchestration-v*` job in `publish.yml` and npm trusted publishing for the package. Both are wave-1 follow-ups.
- It does not port `lane-usage`, the SQLite shim. P-D2 supersedes it.
