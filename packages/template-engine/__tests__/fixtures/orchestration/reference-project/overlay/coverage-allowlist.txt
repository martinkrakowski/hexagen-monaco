# The rule for choosing between the two: a lesson travels when it is about *running a wave* — how
# to dispatch, how to derive status, what evidence counts, what a brief has to contain, what the

# overlay (the cast), or when it is a product, infrastructure or tooling fact that belongs to this
# repository rather than to the orchestrator.
