┌─ INITIALIZATION SEQUENCE ────────────────────────────────────────────────────┐
│                                                                              │
│  t=1-5ms:     Inline script (beforeInteractive) runs BEFORE React           │
│               └─ Sets <html class="dark"> synchronously                     │
│               └─ Reads: localStorage + system preference (media query)      │
│               └─ Result: DOM ready with correct class                       │
│                                                                              │
│  t=6-15ms:    React hydration begins                                        │
│               └─ suppressHydrationWarning on <html>                         │
│               └─ Server/client snapshot comparison                          │
│                                                                              │
│  t=16-20ms:   ThemeProvider mounts                                          │
│               └─ useSyncExternalStore() calls getSnapshot()                 │
│               └─ Result: context = "dark" (matches DOM)                     │
│               └─ CRITICAL: applyTheme() NOT called here (design issue)      │
│                                                                              │
│  t=21-60ms:   Child components mount and render                             │
│               └─ HexagonCanvas: useTheme() → colorMode → ReactFlow          │
│               └─ ReactFlow uses useColorModeClass() hook                    │
│               └─ All CSS active and synchronized                            │
│                                                                              │
│  t=61-100ms:  Hydration complete, page interactive                          │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ STORAGE ARCHITECTURE (HYBRID DIVERGENT MODEL) ──────────────────────────────┐
│                                                                              │
│  THREE independent sources:                                                 │
│                                                                              │
│  1. localStorage ('hexagen-theme')        [Persistent storage]              │
│     └─ Read by: getSnapshot(), inline script                               │
│     └─ Write by: applyTheme() only                                          │
│     └─ Error handling: try/catch in inline script, MISSING in applyTheme   │
│                                                                              │
│  2. <html class="dark">                   [DOM rendering target]            │
│     └─ Set by: inline script + applyTheme()                                │
│     └─ Read by: Tailwind CSS selector matching                             │
│     └─ Problem: Not updated when media query changes                        │
│                                                                              │
│  3. React context (ThemeContext)          [React memory]                    │
│     └─ Populated by: useSyncExternalStore → getSnapshot()                  │
│     └─ Updated by: subscribe() listener triggers re-render                 │
│     └─ Problem: CAN DIVERGE from HTML class                                │
│                                                                              │
│  CONVERGENCE ANALYSIS:                                                      │
│  ✓ On first load: All three sync (inline script + getSnapshot match)      │
│  ✗ On media query change: Context updates but HTML class doesn't           │
│  ✓ On manual toggle: All three sync (applyTheme updates both)              │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ COMPONENT SUBSCRIPTION FLOW ────────────────────────────────────────────────┐
│                                                                              │
│                                                                              │
│  subscribe() LISTENERS:                                                    │
│  ├─ window.addEventListener('storage', onStorage)                          │
│  │  └─ Fires when localStorage changes                                      │
│  │  └─ Triggers getSnapshot() re-evaluation                                │
│  │  └─ Problem: Doesn't call applyTheme() to sync DOM                      │
│  │                                                                          │
│  └─ mql.addEventListener('change', onMediaChange)                          │
│     └─ Fires when system dark mode preference changes                      │
│     └─ Triggers getSnapshot() re-evaluation                                │
│     └─ Problem: Doesn't call applyTheme() to sync DOM                      │
│                                                                              │
│  GETSNAPSHOT() BEHAVIOR:                                                    │
│  ├─ First read: localStorage || system preference                           │
│  ├─ On storage event: Re-reads localStorage                                │
│  ├─ On media query change: Re-reads localStorage || system preference      │
│  └─ Result: Always reads current truth (storage + preference)              │
│                                                                              │
│  REACT RE-RENDER PROPAGATION:                                              │
│  └─ ThemeProvider re-renders → all useTheme() consumers re-render           │
│     ├─ HexagonCanvas updates colorMode prop                                │
│     ├─ ReactFlow receives new colorMode → useColorModeClass runs          │
│     ├─ useColorModeClass useEffect re-runs → className updates            │
│     └─ CSS cascade re-evaluates                                            │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ REACTFLOW INTEGRATION ──────────────────────────────────────────────────────┐
│                                                                              │
│  SOURCE:     useTheme() context → colorMode prop → ReactFlow               │
│                                                                              │
│  FLOW:       HexagonCanvas reads theme                                      │
│             └─ Converts: "dark" | "light"                                   │
│             └─ Passes as colorMode prop                                     │
│             └─ ReactFlow.useColorModeClass() uses useState                 │
│             └─ Initial state: colorMode value                              │
│             └─ useEffect re-runs on dependency change                      │
│             └─ CSS class applied: .react-flow.dark or .react-flow.light    │
│                                                                              │
│  KEY FINDING: ReactFlow does NOT directly subscribe to context              │
│              └─ Prop-based only                                             │
│              └─ Updates on HexagonCanvas re-render                          │
│              └─ Works correctly because HexagonCanvas IS context consumer   │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ TAILWIND DARK MODE MECHANISM ───────────────────────────────────────────────┐
│                                                                              │
│  CONFIG:     darkMode: ["class"]  (not media query)                        │
│                                                                              │
│  BUILD TIME:                                                                │
│  └─ Tailwind JIT compiler scans all files                                   │
│  └─ Generates: .dark .bg-card { ... } (dark mode variant)                  │
│  └─ Also generates: .bg-card { ... } (light mode default)                  │
│                                                                              │
│  RUNTIME:                                                                   │
│  └─ CSS is static (no re-scanning)                                          │
│  └─ When <html class="dark"> is set:                                       │
│     ├─ CSS cascade re-evaluates                                            │
│     ├─ .dark .bg-card selector matches                                     │
│     └─ Dark colors apply                                                   │
│  └─ When <html> has no dark class:                                         │
│     ├─ .bg-card selector matches                                           │
│     └─ Light colors apply                                                  │
│                                                                              │
│  CSS VARIABLES:                                                             │
│  ├─ :root { --background: 35 20% 96%; }      (light mode)                 │
│  ├─ .dark { --background: 35 10% 8%; }       (dark mode)                  │
│  └─ Any element using hsl(var(--background)) gets right colors             │
│                                                                              │
│  SCOPE: GLOBAL (all components inherit via CSS variables)                   │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ CRITICAL RACE CONDITION ────────────────────────────────────────────────────┐
│                                                                              │
│  SCENARIO: User changes OS theme while app is open                          │
│                                                                              │
│  1. OS preference changes dark mode → off                                   │
│  2. Media query listener fires                                             │
│  3. subscribe() callback triggers                                          │
│  4. getSnapshot() re-evaluates:                                            │
│     ├─ localStorage empty (user never toggled)                             │
│     └─ media query now false                                              │
│     └─ Returns "light"                                                     │
│  5. useSyncExternalStore detects change                                    │
│  6. ThemeProvider re-renders                                               │
│  7. context.theme = "light"                                                │
│  8. HexagonCanvas re-renders → colorMode = "light"                         │
│  9. ReactFlow updates .react-flow.light                                    │
│                                                                              │
│  BUT...                                                                     │
│  ✗ <html class="dark"> is STILL SET                                        │
│  ✗ applyTheme() was NEVER called                                           │
│  ✗ Tailwind dark: variant CSS still active                                 │
│                                                                              │
│  RESULT: MISMATCH                                                           │
│  ├─ React context: "light"                                                 │
│  ├─ HTML class: "dark"                                                     │
│  ├─ CSS visible: dark mode (HTML class takes precedence)                   │
│  ├─ ReactFlow: light mode (from context)                                   │
│  └─ Visual inconsistency until next manual toggle                          │
│                                                                              │
│  ROOT CAUSE: subscribe() doesn't sync DOM when media query changes          │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ ROOT CAUSE VERIFICATION ────────────────────────────────────────────────────┐
│                                                                              │
│  Q1: Is getSnapshot() called during init?              YES (correct)       │
│      └─ useSyncExternalStore calls it immediately                          │
│                                                                              │
│  Q2: Does applyTheme() run during init?                NO (BUG)            │
│      └─ Only called from setTheme() / toggleTheme()                        │
│      └─ Design flaw: No sync on mount                                      │
│                                                                              │
│  Q3: Can HTML class and context diverge?               YES (BUG)           │
│      └─ If media query changes, only context updates                       │
│      └─ HTML class stays stale until manual toggle                         │
│                                                                              │
│  Q4: Is there a single source of truth?                NO                  │
│      └─ Hybrid model: localStorage + media query + HTML class              │
│      └─ These can desync if not kept in sync                               │
│                                                                              │
│  Q5: Does suppressHydrationWarning fix the problem?    NO                  │
│      └─ Only suppresses console error                                      │
│      └─ Doesn't prevent visual flicker on mismatch                         │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ RECOMMENDED FIX ────────────────────────────────────────────────────────────┐
│                                                                              │
│  1. Move applyTheme() to module level (not inside useCallback)              │
│  2. Call applyTheme() from subscribe() when media query changes             │
│  3. Add try/catch to localStorage.setItem() for quota errors               │
│                                                                              │
│  IMPACT:                                                                    │
│  ├─ ✓ Fixes media query divergence                                         │
│  ├─ ✓ Syncs DOM class immediately                                          │
│  ├─ ✓ No visual flashing                                                   │
│  ├─ ✓ Negligible performance impact                                        │
│  ├─ ✓ No breaking changes                                                  │
│  └─ ✓ Makes context and DOM always consistent                              │
│                                                                              │
